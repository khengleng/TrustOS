# Curriculum

TrustOS Learn is being designed to support multiple curriculum pathways across Grade 1 through Grade 12.

## Supported Curriculum Families

- Cambridge curriculum
- Cambodia Ministry of Education curriculum

## Language Support

- English
- Khmer
- Bilingual

## Curriculum Intent

The platform should eventually support:

- Grade-specific quiz pathways
- Subject-specific quiz pathways
- Curriculum-aware content organization
- Language-aware content delivery and switching
- Clear separation between curriculum metadata and question content

This repository currently defines shared types for curriculum, grade, and language dimensions only.
