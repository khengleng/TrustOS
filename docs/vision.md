# Vision

TrustOS Learn is intended to become a trusted digital learning platform for Grade 1 to Grade 12 students across Cambodia and beyond. The platform should make high-quality quiz-based learning more accessible, more adaptive, and more multilingual while staying aligned with both local and international curricula.

The product focus is:

- Cambridge curriculum support
- Cambodia Ministry of Education curriculum support
- English learning paths
- Khmer learning paths
- Bilingual learning paths

The long-term direction is an AI-powered learning experience, but this repository foundation does not yet include model integration.
